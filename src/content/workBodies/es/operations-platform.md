### Contexto

La plataforma creció durante años dentro de un framework que hacía cada pantalla nueva más lenta de construir y más difícil de mantener coherente. Los equipos internos lo notaron primero: las herramientas que usaban eran interfaces web pegadas a modelos de datos antiguos.

### Enfoque

- Rehíce el pipeline de entrega antes de tocar funcionalidades, para migrar de forma incremental.
- Llevé el modelo de datos a contratos tipados compartidos entre API y cliente, lo que eliminó la deriva entre ambos.
- Construí las suites internas de gestión en paralelo a la migración, no después.
